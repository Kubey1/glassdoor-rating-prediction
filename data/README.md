# Data

The dataset is not included because it belongs to the course (ECON 424, University of Waterloo).

It contained Glassdoor employee reviews with these columns:

| Column | Description |
|---|---|
| `firm` | Employer name |
| `job_title` | Reviewer's job title |
| `year_review` | Year the review was posted |
| `headline` | Review headline |
| `pros` | What the reviewer liked |
| `cons` | What the reviewer disliked |
| `rating` | Overall star rating, 1-5 (target) |

To run the script, place `small_train.csv` and `test_without_response_v1.csv` in this folder.
